# VelPay Design System

## Overview

El VelPay Design System es un sistema de diseño creado para unificar y escalar las experiencias digitales de VelPay en sus diferentes productos.

## Products

El sistema soporta:

- Terminal POS
- mPOS
- P5
- D60
- Assistant
- Backoffice
- Payment Links

## Objective

Crear una base consistente que permita diseñar y desarrollar productos más rápidos, escalables y alineados entre plataformas.

## Status

Active / Continuous Improvement

UX/UI Design Team
