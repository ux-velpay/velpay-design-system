# Context & History

## Before Design System

Cuando inició el proceso:

- Los diseños estaban en Sketch.
- No existía una librería centralizada.
- Había componentes duplicados.
- Existían diferencias entre productos.
- No había una documentación estándar.

## Initiative

Se inició la creación del Design System para:

- Unificar experiencias.
- Reducir inconsistencias.
- Mejorar colaboración Diseño-Desarrollo.
- Crear componentes reutilizables.

## Migration

Proceso realizado:

Sketch → Figma → Component Library → Tokens → Documentation
